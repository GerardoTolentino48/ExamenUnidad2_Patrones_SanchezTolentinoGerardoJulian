--------------PROYECTO ASIGNADO-------------------
Juego de gestión de una ciudad virtual

El simulador de juego en formato visual utiliza la estructura lógica de patrones de diseño: "Singleton" y "Object Pool", esto con el fin de tener una mejor estructuración de código

----------------COMO CORRERLO---------------------
Este codigo es bastante simple en su ejecución, basta con tener descargados el html y el css dentro de una misma carpeta y en el explorador de archivos dar doble clic sobre el html,
esto abrirá una página en chrome con la lógica y estilos CSS funcionando correctamente.
